# Прогнозирование свойств композиционных материалов

ВКР по курсу Data Science PRO. Автор исходной работы: Чеченов Алим Маликович.

Локальное приложение получает прогноз из сохранённых Python-конвейеров. Два режима: **модуль и прочность** — 11 входов и два регрессора Ridge; **соотношение матрица-наполнитель** — 10 входов и сеть MLP 10 → 16 → 1. Повторного обучения при работе приложения нет.

## Быстрый запуск

Рекомендуемая воспроизводимая среда — **Python 3.13.5**. Для моделей зафиксирован **scikit-learn 1.8.0**. Распакуйте весь каталог `app_for_vkr`, а не один файл. Все команды выполняются из этого каталога. При первой установке зависимостей нужен доступ к PyPI; после установки приложение работает без интернета.

### Windows (PowerShell или командная строка)

```powershell
py -3.13 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-app.txt
.venv\Scripts\python.exe app.py
```

### macOS / Linux

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements-app.txt
.venv/bin/python app.py
```

Откройте **http://127.0.0.1:8000** в браузере. Терминал должен оставаться открытым. Остановка сервера — **Ctrl+C**. Для следующего запуска достаточно последней команды: создавать окружение и устанавливать зависимости повторно не нужно. Активация окружения не требуется, поскольку указан путь к его интерпретатору.

Если порт занят, добавьте `--port 8001` к команде запуска и откройте http://127.0.0.1:8001. Сервер всегда привязан к `127.0.0.1`; доступ из локальной сети или интернета не предусмотрен.

## Работа с формой

Выберите режим. Введите показатели в исходных единицах или нажмите **«Заполнить пример»**, затем **«Рассчитать прогноз»**. Кнопка **«Очистить»** очищает поля. Пример соответствует строке с индексом 604, входящей в обе очищенные обучающие части, и не является рекомендуемым составом.

Ввод принимает десятичную точку, запятую и научную запись. Пустые значения, текст, NaN и бесконечность отклоняются. Плотность материала, входной модуль и соотношение должны быть положительными; количества компонентов, поверхностная плотность, шаг и плотность нашивки — неотрицательными. Поддерживаются только углы 0° и 90°, представленные в исходных данных. Это ограничение области применения интерфейса, а не утверждение о физической невозможности других углов.

Нулевые шаг и плотность нашивки не объявляются автоматически ошибками: такие значения присутствуют в исходных таблицах. Верхнее ограничение «100 процентов» для количества отвердителя не вводится, поскольку смысл базы этого показателя в источнике не раскрыт и в данных есть значения выше 100.

Обучающие диапазоны извлекаются из `MinMaxScaler` сохранённых моделей. Выход за диапазон вызывает предупреждение, но число не заменяется и не обрезается. После изменения любого поля, очистки или подстановки примера старый результат скрывается; при смене режима открывается новая пустая форма. Описание Ridge и архитектуры MLP в результате формируется по фактически загруженным моделям, а не по заранее заданной строке. JavaScript используется только для управления формой, не для вычисления моделей. Для этих интерактивных функций JavaScript должен быть включён.

## Повторение исследования

В созданном окружении установите `requirements.txt`, затем откройте JupyterLab. Например, для macOS / Linux:

```bash
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m jupyterlab composite.ipynb
```

На Windows замените `.venv/bin/python` на `.venv\Scripts\python.exe`. Запустите все ячейки ноутбука по порядку, начиная с первой. Ноутбук должен находиться рядом с исходными XLSX. Он использует INNER-объединение по индексу, разделение 70/30 и сеточный поиск с перекрёстной проверкой на 10 блоках. Границы IQR и масштабировщик определяются внутри обучающих блоков. Последняя ячейка **перезаписывает `models.joblib` и `examples.json`**; сохраните их копии перед повторным исследованием. После пересохранения моделей перезапустите приложение.

Первая кодовая ячейка выводит фактические версии Python и библиотек и проверяет соответствие итоговой среде. `results/environment.json` содержит версии и SHA-256 исходных таблиц. Числовые результаты экспортируются в `results/metrics.csv` и `results/cv_*.csv`.

Перед сохранением моделей ноутбук вызывает `report_figures.export_report_figures`: заново строятся рисунки 1–4, 6–17 и 19 из пояснительной записки. Файлы сохраняются в `figures/figure_XX.png`, номера и контрольные суммы — в `figures/manifest.json`. Они используются в записке и презентации без дополнительной ручной отрисовки. Схемы 5 и 18 и снимки интерфейса 20–21 оформлены отдельно. При изменении исследования перенесите обновлённые PNG также в документы; ноутбук не редактирует Word или PowerPoint автоматически.

## Результаты и ограничения

| Цель | Модель | MAE на тесте | R² на тесте |
|---|---|---:|---:|
| Модуль при растяжении | Ridge, alpha=100 | 2,5604 ГПа | −0,0189 |
| Прочность при растяжении | Ridge, alpha=100 | 378,7745 МПа | 0,0026 |
| Соотношение | MLP, 10–16–1, alpha=1 | 0,7727 | −0,0435 |

Устойчивое преимущество над прогнозом среднего не подтверждено. Это учебная демонстрация, не замена испытаниям и не система оптимизации рецептуры. Ошибки относятся к выборке в целом, а не к гарантированной погрешности отдельного прогноза. Предупреждения о диапазонах не являются полной физической верификацией состава.

Файл `models.joblib` должен происходить из доверенного комплекта: загрузка сторонних pickle/joblib-файлов небезопасна. Не размещайте этот локальный учебный сервер в интернете.
